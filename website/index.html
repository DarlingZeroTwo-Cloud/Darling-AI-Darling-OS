文本对话

标准 OpenAI 接口，支持流式与非流式。模型 ID 固定为 02：

curlcurl https://api.darling02.de5.net/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <你的API_KEY>" \
  -d '{
    "model": "02",
    "messages": [{"role": "user", "content": "用一句话介绍你自己"}],
    "stream": false
  }'
Pythonfrom openai import OpenAI

client = OpenAI(
    base_url="https://api.darling02.de5.net/v1",
    api_key="dl-你的API_KEY",
)
resp = client.chat.completions.create(
    model="02",
    messages=[{"role": "user", "content": "你好，介绍一下你自己"}],
)
print(resp.choices[0].message.content)
Node.jsconst { OpenAI } = require("openai");
const client = new OpenAI({

流式输出

把请求体里的 stream 设为 true，即可获得 SSE 流式响应，逐字返回内容，适合聊天类应用。

错误码

状态码含义处理建议
401未登录 / API Key 无效检查 Authorization Header 是否正确
404模型不存在 / 接口路径错误确认模型 ID 为 02、路径为 /v1/...
429请求过于频繁 / 上游限流稍等片刻重试（服务端已自动重试一次）
502上游服务异常稍后再试，若持续请反馈

注意：如果返回纯文本 error code: 1015，是访问网络被临时限流，换网络或稍等即可。

使用指南

从注册到调用，一份指南全部搞定

1. 注册与登录

打开官网点击「注册」，填写邮箱、密码、安全问题和答案即可完成注册。在 DARLING-AI 客户端注册过的账号，同一个邮箱可以直接在这里登录，无需重复注册。

登录后永久有效，不需要重复输入密码（除非你手动退出）。

2. 获取 API Key

登录后进入「控制台」，点击「创建 API Key」。Key 只会完整显示一次，请立即复制保存。如果怀疑泄露，随时可以在控制台删除重建。

3. 在客户端中使用

下载并安装 DARLING-AI 客户端（Windows / Linux），登录同一账号后，模型供应商中会自动出现官方模型 02，直接选择即可对话和生图。

4. 在第三方工具中使用

任何支持「自定义 OpenAI 接口」的软件（ChatBox、NextChat、各类 AI 插件等），填入：

  • Base URL：https://api.darling02.de5.net/v1
  • API Key：你创建的 dl-...
  • 模型：02

常见问题

02 是什么？

02 是 DARLING-AI 生态的官方 AI 助手，由 DARLING-AI 开发，支持文本对话和图片生成，注册即可免费使用。

API 免费吗？有限制吗？

免费，官方模型不限制对话次数和图片生成次数。如遇上游繁忙会临时限流，稍等重试即可。

API Key 泄露了怎么办？

立即到控制台删除该 Key，再创建一个新的即可，旧 Key 会立即失效。

忘记密码怎么办？

在登录页点击「忘记密码」，输入邮箱后会显示你注册时设置的安全问题，答对即可设置新密码。

客户端和官网的账号通用吗？

通用。同一个邮箱注册一次，客户端和官网都能登录，模型配置等个性化设置会同步。

对话记录会保存吗？

对话内容不会被保存到服务端，隐私安全；只有模型配置、API Key 等账号设置会云端同步。
